Versión con 12 fotografías reales seleccionadas para M&M Construcciones, incluida la nueva muestra de reparación y mantención de piscinas.

Se mantiene la estructura, navegación y diseño de la web. Se sustituyen las imágenes ilustrativas por fotografías locales optimizadas en public/images/portfolio.

Para ver la vista previa, abre vista-previa.html desde esta carpeta.
Para publicar, ejecuta npm install y npm run build; Astro genera el sitio en dist/.
