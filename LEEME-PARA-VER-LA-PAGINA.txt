VISTA PREVIA DE M&M CONSTRUCCIONES

1. Descomprime el archivo ZIP completo.
2. Abre la carpeta mm-construcciones-web-final.
3. Haz doble clic en vista-previa.html.
4. Se abrirá una vista general de la web en tu navegador.

Importante: mantén la carpeta public junto al archivo vista-previa.html para que se carguen el logotipo y las fotografías.

El sitio completo está desarrollado en Astro. La página de inicio editable está en src/pages/index.astro.
La información de los servicios y proyectos está centralizada en src/data/site.js.

Para ejecutar el sitio completo localmente:
- Instala Node.js 20 o superior.
- Abre una terminal dentro de la carpeta del proyecto.
- Ejecuta: npm install
- Luego ejecuta: npm run dev

Para generar la versión de producción:
- Ejecuta: npm run build
- Astro generará el sitio en la carpeta dist/.

PARA ACTUALIZAR GITHUB
1. Descomprime el ZIP.
2. Abre la carpeta mm-construcciones-web-final.
3. Sube el CONTENIDO de esa carpeta al directorio principal del repositorio GitHub, conservando las carpetas src y public.
4. No subas el ZIP como un único archivo ni crees una carpeta anidada adicional.
5. Confirma el commit. Si Render tiene Auto-Deploy activado, comenzará una nueva publicación automáticamente.
